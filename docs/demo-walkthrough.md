# End-to-End Demo & Live Walkthrough Guide

This walkthrough provides a 2-minute script demonstrating the end-to-end capabilities of the **Transaction Risk Monitoring & Alerting System**.

---

## 1. Start the System

```bash
# Option A: Start using Docker Compose
docker compose up -d

# Option B: Run locally
# Start PostgreSQL on port 5433 (or 5432)
cd backend && mvn spring-boot:run
```

Verify service health:
```bash
curl -s http://localhost:8080/actuator/health
```

---

## 2. Ingest a Suspicious Transaction

Ingest a single high-value transaction ($2,500 on account 1) triggering the **Unusual Amount** rule:

```bash
curl -u analyst1:Analyst123! -X POST http://localhost:8080/api/transactions \
  -H "Content-Type: application/json" \
  -d '{
    "accountId": 1,
    "merchantId": 12,
    "deviceId": 5,
    "amount": 2500.00,
    "currency": "USD",
    "country": "US",
    "txnTime": "2026-11-06T12:00:00Z",
    "channel": "ONLINE"
  }'
```

**Expected Response (HTTP 201 Created):**
```json
{
  "id": 105001,
  "accountId": 1,
  "merchantId": 12,
  "deviceId": 5,
  "amount": 2500.00,
  "currency": "USD",
  "country": "US",
  "txnTime": "2026-11-06T12:00:00Z",
  "channel": "ONLINE",
  "alertsGenerated": 1,
  "triggeredRules": ["UnusualAmountRule"]
}
```

## 3. Review Alert Queue (Analyst Triage)

List active OPEN alerts as `analyst1`:

```bash
curl -u analyst1:Analyst123! -X GET "http://localhost:8080/api/alerts?status=OPEN"
```

**Expected Response (HTTP 200 OK):**
```json
{
  "content": [
    {
      "id": 4020,
      "txnId": 105001,
      "ruleName": "UnusualAmountRule",
      "severity": "HIGH",
      "status": "OPEN",
      "assignedToUsername": null,
      "reason": "Transaction amount $2500.00 is 10.0x above account 30-day average ($124.50)"
    }
  ]
}
```

---

## 4. Claim the Alert (State: OPEN → IN_REVIEW)

The analyst claims the alert to take ownership:

```bash
curl -u analyst1:Analyst123! -X POST http://localhost:8080/api/alerts/4020/claim
```

**Expected Response (HTTP 200 OK):**
```json
{
  "id": 4020,
  "status": "IN_REVIEW",
  "assignedToUsername": "analyst1"
}
```

---

## 5. Escalate the Alert (State: IN_REVIEW → ESCALATED)

Upon investigation, the analyst notes suspicious indicators and escalates to management:

```bash
curl -u analyst1:Analyst123! -X POST http://localhost:8080/api/alerts/4020/escalate \
  -H "Content-Type: application/json" \
  -d '{
    "reason": "Amount spike combined with recent overseas inquiry; escalating to Manager for account block."
  }'
```

**Expected Response (HTTP 200 OK):**
```json
{
  "id": 4020,
  "status": "ESCALATED",
  "assignedToUsername": "analyst1"
}
```

---

## 6. Manager Decision & Close (State: ESCALATED → CLOSED_CONFIRMED)

Managers have exclusive authorization to resolve escalated cases:

```bash
curl -u manager1:Manager123! -X POST http://localhost:8080/api/alerts/4020/close \
  -H "Content-Type: application/json" \
  -d '{
    "outcome": "CONFIRMED",
    "comment": "Confirmed fraud. Account frozen and merchant notified."
  }'
```

**Expected Response (HTTP 200 OK):**
```json
{
  "id": 4020,
  "status": "CLOSED_CONFIRMED"
}
```

*(Note: If `analyst1` attempts to close an escalated alert, HTTP 403 Forbidden is returned).*

## 8. Database-Level Immutability Proof

Direct modifications to `audit_log` are blocked at the PostgreSQL engine level:

```sql
UPDATE audit_log SET details = 'tampered' WHERE id = 1;
-- ERROR: audit_log entries are immutable: updates are prohibited.

DELETE FROM audit_log WHERE id = 1;
-- ERROR: audit_log entries are immutable: deletions are prohibited.
```

## 9. Machine Learning Anomaly Detection Benchmark

Show the out-of-time evaluation benchmarking deterministic rules against Isolation Forest:

```bash
python ml/evaluate.py --port 5433
```

Displays the precision, recall, F1 score, and daily analyst alert workload across:
- **Rules Only:** 33.38% Precision, 64.91% Recall, 37.4 alerts/day
- **Isolation Forest:** 27.05% Precision, 40.60% Recall, 28.9 alerts/day
- **Combined (Rules OR ML):** 24.59% Precision, 67.42% Recall, 52.7 alerts/day
